# このブログについて

はじめまして、**リラ**と申します。  
現在、Web開発を中心に技術を学んでおり、学んだことを実際のプロジェクトとしてアウトプットしながら、エンジニアとしてのスキルアップに取り組んでいます。

## 🎯 このブログの目的

このブログでは、業務外で取り組んだ **個人開発プロジェクト** や **GitHub上の成果物** を紹介しています。  
実際のコードとともに、設計思想や技術選定の理由、開発過程で得た学びを発信することで、  
エンジニアとしての成長を可視化することを目指しています。

## 💻 技術スタック

### フロントエンド
- **TypeScript / JavaScript** — React, Next.js, Astro, Svelte
- **HTML / CSS** — Tailwind CSS, レスポンシブデザイン

### バックエンド
- **Node.js** — Express, API設計
- **Python** — スクレイピング, 自動化ツール

### インフラ / DevOps
- **Docker** — コンテナ化, DevContainer
- **GitHub Actions** — CI/CD パイプライン
- **Cloudflare** — デプロイ, CDN

### その他
- **Git / GitHub** — バージョン管理, チーム開発
- **LINE Bot / Discord Bot** — メッセージング連携
- **Gemini API** — AI活用
